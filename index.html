MANILA FOLDER · PRIVACY POLICY

개인정보처리방침

시행일: 2026년 10월 27일 · 앱: MANILA FOLDER · Android 패키지: com.manilafolder.archive

MANILA FOLDER는 건축물 정보, 사진 및 태그를 개인적으로 기록·조회하는 앱입니다. 대부분의 기록은 사용자의 휴대전화에 보관되며, 사용자가 지도·주소 검색·건축정보 조회 또는 OneDrive 백업 기능을 이용할 때에 한하여 해당 외부 서비스와 정보가 통신될 수 있습니다.

1. 처리하는 정보

  • 사용자가 저장하는 기록: 건축물명, 주소, 건축정보, 메모, 사진, 사진별 태그, 대표사진, 정렬 순서 및 즐겨찾기.
  • 선택한 외부 기능의 정보: 주소·장소 검색어, 지도에 표시할 위치 및 지도 요청, 공공건축정보 조회 조건, 이용자가 직접 설정한 공공데이터 API 인증키.
  • 선택적인 OneDrive 연동 정보: Microsoft 로그인 계정 표시 정보, 인증 상태, 선택한 백업 폴더 정보 및 백업 파일. Microsoft 로그인 토큰은 앱의 Microsoft 인증 라이브러리에서 처리합니다.
  • 인터넷 통신 정보: 외부 제공자의 웹 서버 접속 과정에서 IP 주소, 요청 시각 등 일반적인 네트워크 정보가 해당 제공자에게 전달될 수 있습니다.

앱은 기기 GPS 권한이나 연락처 권한을 필수로 요청하지 않습니다. 건축물의 주소 또는 지도 위치는 사용자가 조회하거나 저장하는 정보입니다.

2. 저장 위치와 이용 목적

사용자가 등록한 건축물 기록과 사진, 태그 등은 원칙적으로 앱의 휴대전화 내부 저장 공간(IndexedDB 등)에 저장되어 개인 건축 아카이브 표시, 검색, 분류, 지도 표시 및 복원에 이용됩니다. 앱 운영자가 관리하는 별도의 계정 서버로 모든 사진이나 건축물 기록을 일괄 수집하는 구조는 아닙니다.

공공데이터 API 인증키 및 일부 설정값은 Android의 보호된 앱 저장소에 보관될 수 있습니다. 키는 사용자가 요청한 건축정보 조회를 수행하는 데 이용됩니다.

3. 외부 서비스 제공자와 정보 전송

MANILA FOLDER에는 다음과 같은 외부 서비스 연동 기능이 포함되어 있습니다. 사용자가 해당 기능을 이용하면 필요한 요청 정보가 각 서비스에 전달될 수 있으며, 외부 서비스 제공자의 데이터 처리에는 각 제공자의 정책이 적용됩니다.

  • Microsoft (OneDrive 및 Microsoft 로그인): 사용자가 연결을 선택하면 Microsoft 인증 서비스와 Microsoft Graph를 통해 계정 연결 및 사용자가 선택한 폴더의 백업 파일 업로드·조회가 이뤄집니다. 앱은 로그인 과정에서 Microsoft Graph의 파일 읽기·쓰기 권한을 요청할 수 있습니다. 사용자가 백업 설정과 자동 백업을 활성화했다면 선택한 저장 위치로 백업이 반복될 수 있습니다.
  • 국토교통부 공공데이터 서비스(data.go.kr): 건축물대장 및 인허가정보 조회에 필요한 조회 조건과 사용자의 API 인증키가 전송될 수 있습니다.
  • OpenStreetMap Nominatim 및 OpenFreeMap: 주소·장소 검색어, 지도 표시를 위한 요청과 지도 영역 정보가 해당 서비스에 전송될 수 있습니다.
  • 카카오/다음 우편번호 서비스: 주소 찾기 기능을 사용할 때 검색 내용 및 서비스 요청 정보가 해당 서비스에 전달될 수 있습니다.
  • unpkg CDN: 지도 표시를 위한 MapLibre 관련 리소스를 불러올 때 일반적인 웹 요청 정보가 CDN 사업자에게 전송될 수 있습니다.

위 연동은 앱의 기능 제공을 위한 것이며, 앱 코드상 자체 광고 SDK나 자체 이용행태 분석 SDK는 포함되어 있지 않습니다. 이는 외부 서비스의 자체 접속 로그 처리까지 없다는 의미는 아닙니다.

4. 보유 기간 및 삭제

  • 기기 내부 기록: 사용자가 해당 기록을 삭제하거나 앱 데이터를 삭제할 때 제거할 수 있습니다. 앱 삭제 시 기기에만 남아 있던 사진과 기록은 복구하지 못할 수 있으므로, 삭제 전에 백업 여부를 확인해야 합니다.
  • OneDrive 백업: 백업 파일은 이용자의 Microsoft 계정에서 관리됩니다. 앱 삭제 또는 로그아웃만으로 OneDrive 파일이 자동 삭제되는 것은 아닙니다. 이용자는 본인 OneDrive에서 백업 파일을 직접 삭제할 수 있습니다.
  • 인증 정보와 설정: 앱 설정 변경 또는 앱 데이터 삭제로 제거할 수 있습니다. 외부 서비스에 보존된 계정 정보·접속 기록 등은 해당 제공자의 보존 및 삭제 정책을 따릅니다.

5. 보안

앱은 통신에 HTTPS를 사용하며, 공공 API 키 등 일부 인증정보는 Android의 보호된 저장소에 보관합니다. 다만 이용자의 기기 보안 상태 및 외부 서비스의 보안 정책 등에 따른 위험이 완전히 제거되는 것은 아닙니다. 계정 비밀번호와 개인 인증키를 다른 사람에게 공유하지 마세요.

6. 이용자 선택 및 권리

이용자는 앱에서 건축물과 사진 등의 정보를 관리·삭제할 수 있으며, 선택한 백업 파일을 복원할 수 있습니다. OneDrive 연결은 선택 기능이고, 연결·해제와 클라우드 파일 삭제는 별개의 작업입니다. 개인정보 처리와 삭제에 관한 문의는 아래 연락처로 보내 주세요.
